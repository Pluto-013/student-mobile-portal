# student-mobile-portal
A student portal project for practicing Git and GitHub collaboration.
## Components
- **StudentProfile**: Displays a student's basic details including name, student ID, and degree program.

### Integration & Usage
1. Place `StudentProfile.jsx` in your project's component directory (e.g., `src/`).
2. Import and render the component in your React application:
```jsx
import StudentProfile from './StudentProfile';
function App() {
  return (
    <div>
      <StudentProfile />
    </div>
  );
}
export default App;
